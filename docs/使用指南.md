# 栖间完整使用指南

## 书桌和桌宠

| 入口 | 功能 |
| --- | --- |
| 台历 | 月历、日期详情、当天待办 |
| 单词卡 | 四六级复习、自定义词汇 |
| 白纸 | 多张便签 |
| 笔筒 | 可保存的多画布画板 |
| 平板 | 本地视频仓库，桌面同时显示本机时间 |
| 手柄 | 四个本地小游戏 |
| 单词卡上方偏右的灰紫半球 | 切换日景和夜景 |

悬停时物件会高亮。用鼠标点击进入，功能页顶部的「回到书桌」可以返回。桌宠只在栖间窗口内活动。按住它可以拖动，点头或身体可互动。右键打开聊天，展开「动作与互动」可选择其他动作。方向键移动，Shift 加速，Home 归位，Esc 停止当前动作。

在「陪伴设置」可切换「是否按照当前时间变换场景」。默认开启，按电脑本地时间 06:00 至 18:00 前显示日景，其余时间为夜景。自动模式下，手动切换后约十秒回到当前时段，连续点击会重新计时。关闭自动模式后会保留最后一次手动选择。

## AI 聊天与情景陪伴

1. 在 DeepSeek 官方控制台创建自己的 API Key，确保账户已开通 API 服务。
2. 右键波奇酱，点齿轮「陪伴设置」。填写 Key 和账户可用的模型 ID。连接地址由应用设置为 DeepSeek 官方 API。
3. 点「保存并测试」核对连接及可用模型。如果要试识图，点「测试识图」。该按钮用纯色测试图验证配置。
4. 返回输入框，输入想说的话。Enter 发送，Shift+Enter 换行。回复显示在桌宠附近的气泡里，也可以打开聊天记录回看。

作者演示用 Key 将于 **2026 年 12 月**撤销。安装包内没有作者的 Key，使用自己的 Key 才能聊天和触发 AI 反馈。使用 API 会在你的账户上产生调用费用。

**主动回应。** 开启后，波奇酱会在合适的时候结合便签、待办、单词复习、画板或游戏等当前操作给出反馈。出现频率取决于活泼程度、当前界面、内容变化和模型返回。想只在主动提问时聊天，可以关闭主动回应。

**窗口识图。** 开启后，可在聊天中使用「看看当前画面」，或在主动陪伴时按设置的间隔检查当前功能页。画面相同、正在打字或窗口隐藏时会跳过观察。识图需要所填模型实际支持图片。关闭识图仍可基于本地功能数据做文字回应。波奇酱可以读取视频仓库的标题、分类和播放状态等信息，无法仅凭标题了解整段视频内容。

**个性化。** 在陪伴设置里可编辑称呼和偏好，调整回复语言、气泡字体、字号、活泼程度和观察间隔。桌宠会使用这些设置和近期对话来保持上下文。气泡出现后可悬停阅读，拖动桌宠会收起旧气泡。

**聊天和记忆。** 清空对话会移除本机聊天和近期活动。长期记忆在陪伴设置的「记忆」里单独管理，可查看、编辑、添加、逐条删除、全部清空或关闭自动整理。手动填写的称呼和偏好需要在设置中单独清空并保存。更换 Key 可重新填写，移除 Key 使用设置里的删除操作。

## 日历和便签

**日历。** 点台历看月历，支持翻月、回到今天、跳转指定日期和查询节日、农历及节气。点击某一天查看当天详情并添加待办，支持标为重要、完成和删除。日历支持 1901–2099 年，节日标注不代表法定调休安排。待办保存在本机，应用不提供系统提醒。

**便签。** 点白纸后新建便签，输入标题和正文，可换便签颜色。修改会自动保存。导出 JSON 可备份，导入会追加便签。误删可在本次会话内按提示撤销。保存失败时保留当前草稿，可重试或先导出。

## 单词卡

1. 点单词卡，选择全部、四级、六级备考（含四级基础）、六级进阶或自定义。
2. 先回想当前英文单词，再点「显示释义」。
3. 用「忘记了」「有点难」「记住了」「很轻松」评价这次复习。系统根据评分安排下次复习，同一词在不同分类间共用进度。误评分可撤销。
4. 「管理词库」支持搜索、分页和新增自定义词。支持批量导入两列词汇，以及导出和恢复学习备份。导入前先导出当前备份，便于找回原有进度。

内置四级 4,543 词，六级来源表 3,991 词，两表去重共 6,661 词，其中四级之外的六级进阶有 2,118 词。此处的分类来自仓库附带的开源词表。词库当前不含内置发音或拼写测试。「今日复习」统计操作次数。

## 画板

点笔筒打开画板。首启的「波奇酱 SAMA」示例由原始手写笔迹组成，可编辑。画板支持画笔、形状、文字、插入图片、选择和移动。右上工具可新建、重命名、打开画稿、导出图片或 `.excalidraw` 文件。

- **关闭画布**会保存画稿，可从「重新打开画布」找回。**删除画布**需要确认，删除后从本地画稿中移除。
- **画布背景**可选择预设或自定义颜色。白天新建白底、夜晚新建黑底，已保存画布按其原色显示。
- **重置画布**会清空当前画稿内容、恢复背景和视图，操作前需确认。可按 Ctrl+Z 撤销内容清空。
- 画稿和图片自动保存在本机。转移到另一台设备时可导出画稿，再在目标设备打开。画板菜单的 GitHub 链接通过系统浏览器打开。

## 视频仓库

点平板进入。正式包首启内置《栖间》字幕版和《11月3日》。可以把本机视频拖入仓库或选择文件导入。导入会把文件复制到本地仓库，搬动原文件后仍能播放。相同内容会去重。

可按名称搜索、重命名、建立和调整分类。删除分类只会把里面的视频移到「未分类」。删除视频会移除仓库副本，原文件由你自己管理。播放器支持暂停、跳转、倍速、音量、全屏和保存播放进度。推荐 MP4（H.264/AAC）或 WebM，容器扩展名相同的文件仍可能因编码不同而无法播放。

## 游戏

点手柄，在游戏房间选择「回旋镖冒险」「元素沙盘」「六角消除」或「水果篮子」。进入后按游戏界面提示操作。顶部按钮可暂停、继续、重开、回到游戏选择或回到书桌。离开当前游戏时会提示是否结束本局。水果篮子会保留本机最佳分，当前游戏局面不保证跨重启恢复。

## 数据、隐私和故障处理

- Windows 正式版的数据在 `%APPDATA%\栖间正式版`。便签、待办、学习进度及画稿存放在应用本地存储，视频和 AI 配置使用同一数据目录下的各自子目录。解压或移动程序目录后，该数据仍留在本机。
- API Key 由 Electron 使用 Windows 系统加密存储。不要把 Key 写到画稿、便签、截图或错误报告里。
- 发送聊天时，相关近期对话、记忆、偏好和所需的当前组件信息可能提交给 DeepSeek。启用窗口识图时，当前栖间应用画面也可能提交给 DeepSeek，其中可能有便签正文或画稿。应用的识图只截取自己的窗口，截图不作为本地文件保存。视频文件存放在本机。
- 登录 API 不成功时，核对 Key、账户余额和模型 ID。聊天可用但识图失败时，先用「测试识图」，再确认所选模型的图片输入支持。
- 如果部分窗口缩放后看不清，先把栖间窗口放大。若下载后打不开，检查 ZIP 是否完整解压，以及 EXE 是否仍和 DLL、`resources` 同目录。
- 更换电脑前，便签和词库可用各自的备份导出，画稿可导出 `.excalidraw`。整目录备份应先退出栖间。Windows 加密的 Key 应在新电脑重新配置。
