# 源码运行、打包与素材归属

## 运行和打包

项目使用 Electron、React、TypeScript 和 electron-vite。使用 Node.js 24 和 npm，在 Windows 上执行：

```powershell
cd companion-desktop
npm ci
npm run dev
```

`npm run typecheck` 检查主进程和渲染进程类型，`npm run build` 生成可发布的应用源码产物，`npm run build:win` 生成 Windows x64 解包目录 `dist/win-unpacked`。打包时保留整个目录，里面的入口为 `栖间.exe`。要重新生成图标，先安装 Python 的 Pillow，再运行 `python scripts/generate-icon.py`。

发布 ZIP 已包含两段视频。源码默认不存放二进制视频。若要从源码复刻同样的内置视频，可从正式 ZIP 的 `resources/starter-videos` 取两段 MP4，再执行：

```powershell
python scripts/prepare-release-media.py <qijian-demo.mp4的路径> <november-03.mp4的路径>
npm run build:win
```

该脚本生成视频副本、尺寸和 SHA-256 索引。应用在新视频目录初始化时导入一次。后续重启不会恢复用户已从仓库删除的条目。默认画稿只保存手写笔迹，不携带开发画板数据库。正式包使用独立的应用数据目录，运行时产生的聊天、用户设置、密钥和缓存不属于源码或安装包。

## 源码布局

| 目录 | 内容 |
| --- | --- |
| `companion-desktop/src/main` | Electron 窗口、AI、游戏协议和视频仓库 |
| `companion-desktop/src/preload` | 主进程与界面的受控 IPC 接口 |
| `companion-desktop/src/renderer/src` | 书桌、桌宠、聊天和各组件 |
| `companion-desktop/src/renderer/public` | 本地游戏、字体构建目录和第三方许可证 |
| `third_party/vocabulary` | 四六级来源词表及许可证 |

## 第三方项目与素材

- 桌宠角色与动画来自 [VPet](https://github.com/LorisYounger/VPet)。来源说明见 [VPet 记录](../third_party/vpet/README.md)，应用中附带相应许可。
- 画板基于 [Excalidraw](https://github.com/excalidraw/excalidraw)，词汇复习调度使用 ts-fsrs。字体及对应许可见应用的第三方许可文件。
- 四六级词表来自 [english-vocabulary](https://github.com/KyleBing/english-vocabulary)。固定版本、词数与许可见 [词表说明](../third_party/vocabulary/README.md)。
- 游戏各自的许可和集成记录随 `companion-desktop/src/renderer/public/games` 中对应目录提供。
