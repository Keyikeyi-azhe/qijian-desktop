# 栖间

栖间是一款 Windows 桌面陪伴应用。打开应用会看到一张可交互的书桌。点击书桌上的物件可以做计划、背单词、记笔记、画图、看视频或玩小游戏。桌宠波奇酱会在窗口里活动，配置 AI 后可以就当前操作主动回应，也可以和你聊天。

## 下载与上手

1. 在本仓库的 **Releases** 下载 `Qijian-1.0.0-Windows-x64.zip`。
2. 解压整个 ZIP，双击解压目录里的 **栖间.exe**。请让 EXE 和同目录的 `resources` 等文件保存在一起。
3. 在桌上点台历、单词卡、白纸、笔筒、平板或手柄。鼠标悬停时可以看到对应功能。
4. 要使用 AI，右键波奇酱，打开齿轮「陪伴设置」，填入自己的 DeepSeek API Key 和账号可用的模型 ID，再点「保存并测试」。

**作者在演示中使用的 API Key 将在 2026 年 12 月撤销。正式版不附带作者的密钥。每位使用者都需要配置自己的 Key，模型调用按自己的 API 账户计费。** 不配置 Key 也能离线使用书桌、桌宠动作和本地组件。

Windows x64 便携 ZIP 解压后即可运行，无需为使用成品安装 Node.js。应用未做 Windows 代码签名，Windows 可能显示未知发布者提示。

## 首次打开

画板内有一张「波奇酱 SAMA」手写示例，仅包含原笔迹。视频仓库内置《栖间》字幕版和《11月3日》。聊天、记忆、个人设置、便签、日历待办、学习进度和游戏进度从干净状态开始。内置四六级词表是可用词库，初始学习进度为零。
